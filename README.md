# PPT Skills

This repository collects presentation-generation skills as Git submodules.

- ` .agents/skills/guizang-ppt-skill`: Guizang PPT Skill (HTML presentation workflow)
- `.agents/skills/html-ppt-studio`: HTML PPT Studio (HTML/CSS/JS presentations)
- `.agents/skills/ppt-master`: PPT Master launcher; upstream source is in `vendor/ppt-master`.

To clone with the complete upstream skill repositories, use `git clone --recurse-submodules`.

These are repository-level skills. Codex discovers skills under `.agents/skills` when the workspace is opened with submodules initialized.
